# Write rules only where traditions broadly agree, and leave contested questions open

## Context and Problem Statement

The architecture guidelines this repository is modelled on write a rule when "sources disagree and we have to pick one". In ethics, many disagreements are not technical choices but deep questions on which thoughtful people, religions and philosophical schools have disagreed for centuries, such as euthanasia, abortion, eating animals or the limits of free speech. Should the guidelines pick a side?

## Decision Drivers

* Trust across cultures and beliefs: readers of every tradition, religious or not, should be able to use the guidelines.
* Usefulness: guidance must still be concrete, not a survey that never says what to do.
* Honesty: the guidelines should not pretend there is agreement where there isn't, or disagreement where there isn't.

## Considered Options

* Adopt one moral theory or tradition and derive every rule from it
* Decide each contested question by our own judgement
* Write rules only where there is broad agreement, and present the positions on contested questions without taking a side

## Decision Outcome

Chosen option: "Write rules only where there is broad agreement". A key rule needs support from sources that represent wide agreement: international instruments such as the Universal Declaration of Human Rights, professional codes of ethics, and the convergence of the major religious and philosophical traditions. Agreement turns out to be wide: prohibitions on murder, theft, lying and cruelty, duties of fairness, care and keeping promises, and some form of the Golden Rule appear across traditions and in law.

Where serious traditions disagree, the file lists the question under **Open questions**, with a source that sets out the positions and a neutral summary of them. Within a domain, a rule may also follow the field's own code of ethics where that code is widely adopted, even if outsiders debate it, as long as the rule says whose code it is.

### Consequences

* Good, because the rules carry the weight of broad agreement, not one group's view.
* Good, because readers see openly where agreement ends.
* Bad, because some readers will want answers to contested questions that the guidelines won't give. The `ethical-decision-record` skill helps them reason through such questions themselves, using several lenses.
* Bad, because "broad agreement" is a judgement. The consensus criterion in [RANKING.md](../../RANKING.md) and review of each new rule keep it honest.

### Confirmation

The pull request template asks contributors to confirm that new rules state broad agreement and that contested questions are listed as open questions.
