# Decisions about this repository

Decision records for this repository itself, written in [MADR](https://adr.github.io/madr/) format. For recording your own ethical decisions, use the [`ethical-decision-record`](../../skills/ethical-decision-record/SKILL.md) skill.

| ADR | Decision | Status |
| --- | --- | --- |
| [0001](0001-reference-first-guidelines.md) | Reference existing codes and sources first, and back every written rule with a source | Accepted |
| [0002](0002-score-sources-and-rules.md) | Score every source and rule from 1 to 10, grouped into three named levels | Accepted |
| [0003](0003-stable-rule-ids.md) | Give every rule a stable ID that is never reused | Accepted |
| [0004](0004-distribute-as-claude-code-plugin.md) | Distribute the skills as a Claude Code plugin that tracks every commit | Accepted |
| [0005](0005-license-content-and-code-separately.md) | License guideline content under CC BY 4.0 and code under MIT | Accepted |
| [0006](0006-write-rules-only-where-traditions-agree.md) | Write rules only where traditions broadly agree, and leave contested questions open | Accepted |
| [0007](0007-describe-traditions-on-their-own-terms.md) | Describe religious and philosophical traditions on their own terms, without ranking them | Accepted |
